# Farzam Nikbakhsh Jorshari

I'm finishing an MSc in Computer Engineering (AI & Robotics) at the University of Padova. I'm interested in representation learning, graph-based models, and making machine learning systems more reliable.

This account contains experiments and small research projects. I try to keep the code, baselines, and results together, including when a more complicated model doesn't improve on a simpler one.

Some of the work here:

- [GraphMix representation learning](https://github.com/DrNFRZM/graphmix-representation-learning) — testing whether graphs built from tabular records improve learned representations.
- [Temporal-static graph fusion](https://github.com/DrNFRZM/temporal-static-graph-fusion) — comparing ways to combine time-series and static patient data.
- [Reliable ML under shift](https://github.com/DrNFRZM/reliable-ml-under-shift) — studying calibration and uncertainty when the data distribution changes.

I'm currently looking for PhD opportunities in machine learning.
